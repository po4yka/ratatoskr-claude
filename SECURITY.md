# Security Policy for Ratatoskr Claude Archive

Report vulnerabilities privately. Do not publish conversations, Project Knowledge, Artifacts, files, account/organization data, exports, Compliance credentials, or parser errors containing private source text.

Security review is required for archive intake, decompression/paths, files and Artifact rendering, parser changes, Compliance ingestion, external references, BlobStore authorization, portable export, retention/deletion, and telemetry.

Baseline: no consumer browser login/session automation; immutable raw archive first; path/file/count/size/decompression limits; no execution/active HTML; sandbox viewers; content-addressed storage; owner/workspace authorization; encrypted Compliance credentials; unknown record preservation; no source text/filenames in logs.
